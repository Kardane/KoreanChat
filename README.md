# KoreanChat

Minecraft 26.3용 Fabric 및 NeoForge 서버사이드 한글 채팅 모드입니다.
서버에만 설치하면 됩니다. 사용하는 모드 로더에 맞는 JAR을 설치하세요.

- Fabric: `KoreanChat-1.8.jar` (Fabric API 포함 설치)
- NeoForge: `KoreanChat-neoforge-1.8.jar` (NeoForge 26.3)

NeoForge에서는 `/krc` 설정을 플레이어 데이터에 저장합니다. Fabric의 Player Data API에 저장된 설정은 자동으로 옮겨지지 않습니다.

/krc on||off 한글채팅을 끄고 켭니다

이전의 한글채팅 모드가 업뎃이 안되서 만들었습니다
